# Шахматы: доска и движок

Страница `index.html` работает без сборки: доска, движок, подсказки, оценка ходов значками, дебюты, режимы «я белыми» и «я чёрными».

## Файлы
| Файл | Для чего |
|---|---|
| `index.html` | сама страница (на GitHub Pages) |
| `engine.js` | движок (источник правды). Тот же код вставлен в index.html, проверка: `node ci.js sync` |
| `rules.js` | правила шахмат для тестов и матчей |
| `ci.js` | проверки и матчи: `perft`, `tactics`, `sync`, `regress`, `elo` |
| `uci.js` | движок по протоколу UCI (Arena, cutechess, Lichess-bot): `node uci.js` |
| `fetch-openings.js` | собирает `book.json` из списка дебютов Lichess |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | установка как приложения и работа без интернета |
| `chess.yml` | автоматизация GitHub Actions (кладётся в `.github/workflows/chess.yml`) |

## Как выложить (с iPad)
1. Распакуй архив в приложении «Файлы» (нажми на zip).
2. В репозитории: **Add file → Upload files**, выбери все файлы, кроме `chess.yml` и `README.md` (README тоже можно), и **Commit changes**.
3. **Add file → Create new file**, в имени введи `.github/workflows/chess.yml`, вставь содержимое файла `chess.yml` и сохрани.
4. **Settings → Pages**: Source = Deploy from a branch, Branch = main, папка / (root), Save.

## Автотесты
При каждом изменении (вкладка **Actions**) сами запускаются перебор ходов, тактические задачи, проверка совпадения движка и страницы, сравнение с предыдущей версией (только информация).

## Замер силы против Stockfish
**Actions → chess → Run workflow**, task = `elo`. Параметры: партий на уровень, время на ход, уровни Stockfish. Результат: таблица на странице запуска (раздел Summary), записи партий в артефакте `games`.
Шкала Elo у Stockfish приблизительная, итоговая цифра тоже. Чем больше партий, тем надёжнее (хотя бы 20 на уровень).

## Большая книга дебютов
**Actions → chess → Run workflow**, task = `book`. Скрипт скачает список дебютов Lichess и создаст `book.json` (обновляется раз в месяц сам). Страница подхватит его автоматически. По моим сведениям, данные открытые (CC0), но проверь лицензию в репозитории lichess-org/chess-openings.

## Работа без интернета
После первого открытия страница кэшируется. Когда есть интернет, страница всегда берётся свежая; кэш нужен только без сети. После изменения файлов увеличь номер версии `V` в `sw.js`. Запросы к Lichess (таблицы эндшпиля и облако) требуют интернета.

## UCI
`node uci.js`. В Arena: Engines → Install New Engine, укажи node и аргумент `uci.js`. Движок думает по `movetime` или по времени на часах и не прерывается командой `stop`.
